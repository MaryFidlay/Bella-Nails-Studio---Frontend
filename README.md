# 💅 Bella Nails Studio — Frontend
### SPA React — Beauty Salon Appointment Management

🔗 **Live Demo (Netlify):** https://bella-nails-studio.netlify.app/

---

## 🏗️ Overview

Bella Nails Studio frontend is a responsive, production-ready Single Page Application (SPA) built with React.  
It allows users to schedule appointments, manage bookings, and provides a secure admin dashboard.  

The frontend communicates with a backend API (hosted on Render) and supports:

- JWT-based user authentication
- Role-based access (User / Admin)
- Real-time booking availability
- Responsive UI (desktop, tablet, mobile)
- Modern, clean design

---sim\

## 🛠️ Tech Stack

- **Frontend Framework:** React
- **Routing:** React Router DOM
- **Date Picker:** Flatpickr
- **Styling:** CSS3 (Flexbox, Grid, clamp(), Media Queries)
- **Environment Variables:** `VITE_API_URL` for backend API endpoint

---

## Features

- **User:** Register/Login, book and cancel appointments, view personal schedule  
- **Admin:** Login, view all bookings by date, cancel any appointment  
- Responsive design for mobile, tablet, and desktop

---

## Setup

1. Clone the repo: `https://github.com/MaryFidlay/Bella-Nails-Studio---Frontend`  
2. Install dependencies: `npm install`  
3. Create `.env` with `VITE_API_URL=https://bella-nails-studio-backend.onrender.com  
4. Run: `npm run dev`
